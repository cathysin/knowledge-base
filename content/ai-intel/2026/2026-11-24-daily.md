## 1. 英伟达董事会宣布黄仁勋立即恢复出任总裁、CEO 和董事

### 发生了什么

英伟达官方新闻稿称，董事会一致投票，立即恢复黄仁勋担任总裁、首席执行官和董事会成员。董事会主席哈维·琼斯（Harvey C. Jones）表示，经过一系列沟通后，董事会对黄仁勋的坦诚和领导能力感到满意，认为他是带领公司的合适人选；他本人将继续担任董事会主席。新闻稿还写明：在做决定的过程中，董事会收到美国政府高层的意见，并据此相信黄仁勋恢复职位不构成国家安全风险。此前担任临时 CEO 的首席财务官科莱特·克雷斯（Colette Kress）将继续担任 CFO。与此同时，官方强调：鉴于早前有报道称黄仁勋「成为外国情报活动的目标」，由独立董事组成的调查委员会仍会把调查进行到底，黄仁勋表示支持并配合；董事会还新设了由独立董事组成的国家安全与出口管制委员会，并开始招聘首席合规官。美国证券交易委员会（SEC）的 8-K 文件把这项人事变动的最早事件日期记为 2026-11-22（周日），新闻稿和官方对外宣布则在 11-23（周一）。更早的背景是：黄仁勋本月稍早辞去 CEO，CNBC 写明他是在 11 月 13 日辞职，此前有关于多段婚外关系的报道，其中包括一名据称是中国间谍的女子；《纽约时报》周日报道称，与他有关系的爱丽丝·黄（Alice Huang）在此期间曾与中国国家安全部人员有联系。这是媒体报道，不是英伟达官方已证实的调查结论。CNBC 还报道：特朗普总统周一对该台表示，他曾直接或间接与英伟达董事会沟通，并认为黄仁勋「没有做错」；另有消息人士称，美国政府官员上周晚些时候向董事会通报，认为没有违反国家安全法律。官方调查尚未结束。展望日程方面，CNBC 称黄仁勋原定 12 月 1 日接受众议院相关委员会闭门问询，英伟达总法律顾问 12 月 2 日出面，参议院银行委员会主席则表示他将于 12 月 3 日就出口管制问题公开作证。据 CNBC，英伟达股价在宣布后周一收盘上涨 31%。

## 2. OpenAI 把对话版 GPT-6.2 Sol 推进 ChatGPT 常规聊天页

### 发生了什么

OpenAI 在 ChatGPT 更新说明中宣布，面向日常对话优化的 GPT-6.2 开始在聊天页向 Plus、Pro、Business 和 Enterprise 用户全球推送；企业端是否能用，还要看工作区管理员设置。官方写明：ChatGPT 里的这一版由 GPT-6.2 Sol 驱动，针对日常对话做了调整；这次更新只覆盖 ChatGPT 的聊天体验，Work 和 Codex 所用模型不变。公司称，它更擅长处理需要跟细指令、或要上网找信息的复杂请求，也更知道什么时候该追问，例如你问某样东西有没有打折，它可能会主动提出价格下降时再通知你。以下数字都是 OpenAI 自己的内部测试，不是第三方公开榜单：在聊天页的图像理解测试中，GPT-6.2 为 71.7%，GPT-6 为 47.4%；在尤其困难的指令遵循测试中，分别为 78.1% 和 62.5%；在他们测试的最低推理档上，专家级任务内部评估为 65%，高于 GPT-6 的 52%；在内部版 BrowseComp（考模型上网找难问题答案）上，四个推理档都高于 GPT-6，最高档约为 64.5% 对 54.4%。安全方面，官方称青少年安全评估有明显提升，在困难对话中的政策合规率为 91%–94%，高于 GPT-6 的 77%–80%。同日还发布了对应的系统卡。官方这份说明没有点名 Free 或 Go 是否包含在内。

### 对你的工作意味着什么

如果你用的是 ChatGPT Plus、Pro 或公司的 Business／Enterprise 账号，常规聊天页可能会换成这版更擅长跟指令、看图和网上查找的模型；用来对比资料、看图里的细节、或让它按你的优先级整理选项，可能会更顺手。但 Work、Codex 没改，Cursor 里的模型也不等于自动升级。文中百分比都是官方内部评测，转述时不要说成已经被第三方普遍验证的公开成绩。

### 白话

**GPT-6.2 Sol** = OpenAI 的 GPT-6.2 系列里，更偏日常对话和一般任务的那个版本。**聊天页 / Chat tab** = ChatGPT 里平常一问一答的那个界面，不是专门写代码的 Codex，也不是 Work。**系统卡** = 公司发布模型时附带的安全说明，用来交代能力边界和防护措施。**BrowseComp** = OpenAI 用来考模型「上网能不能找到难问题答案」的一套内部测试。

## 3. Anthropic 将「零数据留存 + 企业前沿安全监测」开到公开测试

### 发生了什么

Anthropic 宣布，Enterprise Frontier Safeguards（企业前沿安全保障，简称 EFS）即日起对符合条件的企业开放公开测试，并且可以和「零数据留存」一起用。官方的核心设计是：模型的输入和输出存进客户自己控制的云存储（如自己账户里的 Amazon S3 或 Google Cloud Storage），Anthropic 和云厂商都不留底；监测由自动系统完成，不安排人工查看原文，也不会用这些数据来训练模型。这样做是为了解决一个矛盾：只看单条请求，可能看不出被拆开的攻击或越权行为，但要做跨请求监测，传统上又得把数据留在模型公司这边。官方称，过去几个月已与 100 多家客户共同打磨，其中包括四分之一的财富 100 强，以及医疗、金融服务、法律等对数据可见性要求很严的行业；私人测试阶段的评估方包括桥水（Bridgewater）、Salesforce 和 Stripe。富国银行（Wells Fargo）首席信息安全官 Munish Kumar Sharma 在官方文章中说，日志留在富国自己管理的环境和密钥下，由 Anthropic 负责检测。该功能可通过 Claude 平台、AWS 上的 Claude 平台、Amazon Bedrock，以及 Google Cloud 上的 Claude 使用；微软 Foundry 的支持「即将推出」。符合条件的客户会收到开通指引。云存储本身的读写和密钥费用，由云厂商按常规向客户收取。

### 参考来源

- Anthropic 官方文章（页面未另标时刻）：https://claude.com/resources/articles/zero-data-retention-with-enterprise-frontier-safeguards
- Claude 官方 X 帖，2026-11-23 18:15（UTC）／2026-11-24 02:15（香港时间）：https://x.com/claudeai/status/2124929944530587712
- The Next Web，2026-11-23 21:07（UTC）／2026-11-24 05:07（香港时间）：https://thenextweb.com/news/anthropic-enterprise-frontier-safeguards-zero-data-retention-beta

### 对你的工作意味着什么

金融机构讨论「能不能用最强的模型，又不把对话留在模型公司那边」时，这是一个值得记下的新选项，而且有银行安全负责人出来背书。但它现在是公开测试，只对收到通知的合格客户开放，并不等于香港持牌机构可以直接拿来用、也不等于已经满足本地合规要求。如果有人把「零数据留存」理解成「完全没有记录」，那是不准确的：记录还在，只是改放到客户自己的云账户里，由自动系统做监测。

### 白话

**零数据留存 / ZDR** = 模型公司答应不把你的输入输出长期留在自己这边。**企业前沿安全保障 / EFS** = Anthropic 这套面向企业的监测方案，用来在多轮对话里发现滥用或越权，同时尽量不把数据留在自己手里。**安全个案 / Safety Case** = 系统发现风险后生成的告警，交给客户自己的安全团队去看。

## 4. 谷歌开始让搜索的 AI 模式选接 Wallet，读消费和信用卡优惠（Drive、Gemini 随后到）

### 发生了什么

谷歌宣布，搜索里的 Personal Intelligence（个人智能）开始支持接入更多应用。官方写明：从今天起可以自愿把 Google Wallet 接到搜索的 AI Mode 以及 Gemini 应用，用消费记录来看财务节点、找可削减的日常开支，并按已绑定的卡去匹配现金返还类别、旅行权益和积分；Drive 和 Gemini 应用与搜索之间的互通将在未来几周跟进。这些将加入已经可以选接的 Gmail、Calendar 和 Photos。官方特别强调：如果选择接入 Wallet，AI Mode 只能读取账户信息，不能划转、管理或投资资金。用户可在搜索个性化设置里随时开关；谷歌还说，稍后可在个性化回复下方通过「Personalization」图标查看 AI Mode 用了哪些个人上下文。AI Overviews 和 AI Mode 也会开始更多参考你最近的搜索上下文。

## 5. 智谱 Z.ai 发布旗舰模型 GLM-5.4：官方称首次采用 Loop Transformer，并加入视觉能力

### 发生了什么

智谱旗下 Z.ai 发布 GLM-5.4，官方称之为该公司首个建立在 Loop Transformer（循环 Transformer）上的旗舰模型，并加入视觉能力，把编码从传统写软件，扩展到视频、游戏、三维建模和 CAD 等任务。官方技术说明写到：它把 GLM-5 基座中的 28 层循环跑两轮，规模为 7500 亿参数；公司自称其智能水平可与 2 万亿至 3 万亿参数的模型相比。这是官方自我表述，官方博客没有同时给出一套可公开核对的完整跑分；新浪科技也写明「官方跑分暂未公布」，因此不宜把「可对标 2T–3T 模型」说成已获第三方验证的结论。模型现已在 GLM Coding Plan、ZCode 和 Z.ai Chat 开放；官方称 API「即将推出」，并计划在完成必要的安全加固后负责任地开源权重。Z.ai 官方 X 账号于当天转发现已对所有 GLM Coding Plan 用户开放的说明，随后又发布了正式介绍帖。

- Z.ai 官方 X 账号转发的开通说明，2026-11-23 04:20（UTC）／2026-11-23 12:20（香港时间）：https://x.com/Zai_org/status/2124719658074825004
- Z.ai 官方介绍帖，2026-11-23 10:01（UTC）／2026-11-23 18:01（香港时间）：https://x.com/Zai_org/status/2124805514722771349

### 对你的工作意味着什么

这是过去 24 小时里较重要的中国大模型产品更新，适合作为「国内头部实验室仍在快速迭代编码和视觉能力」的观察点，尤其是它把「写代码」说成解决更多任务的基础能力。但它还不是已经开放、可直接对标的公开 API 主力模型，官方也还没给出可核对的完整跑分。如果只是日常写材料、做研究，不必急着换工具；对外转述时，请标明「可与 2T–3T 模型相比」是官方说法，而不是已核实的横评结果。

### 白话

**参数量** = 模型里可学习的数字有多少，常被用来粗略衡量规模，但不能单凭它判断实际好不好用。**Loop Transformer / 循环 Transformer** = 让同一组层重复跑多轮，想用更少的新参数换更深的推理，而不是把模型无限制地做大。**开源权重** = 把训练好的模型参数公开，让其他人可以自行部署；智谱这次还只是「计划在安全加固后开源」，不是今天已经放出来。

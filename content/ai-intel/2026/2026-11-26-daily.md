## 每日 AI 情报｜2026-11-26（周四）

**今天最大的事：** OpenAI 首席执行官 Sam Altman 宣布，公司已开始向一小部分企业客户测试 Private Inference（私密推理）：用「机密计算」等措施，试图在模型处理提示词和回答的过程中也保护企业数据。官网目前把它标为 Alpha / API Preview，全面开放时间、价格和支持的模型都还没有公布。同一时段，OpenAI 确认将从 12 月起把 ChatGPT 和 Codex 的用量额度合并；Google DeepMind 为科研平台 Antigravity 推出质谱鉴定技能；Anthropic 则公开了用 Claude 智能体把核心接口从 Python 迁到 Rust 的工程过程。

## 1. OpenAI 开始向一小部分企业客户测试 Private Inference：试图在模型运算时也保护提示词和回答

### 发生了什么

OpenAI 首席执行官 Sam Altman 在 X 上发帖称，公司已开始向一小部分客户测试 Private Inference，这是 OpenAI Private Intelligence（面向企业敏感工作的隐私方案）中的最新一项。他写道，更强的隐私保护会让前沿模型能用于更多工作，企业隐私对健康的生态也很重要，有兴趣的公司可联系 OpenAI 相关负责人。官方产品页把该功能标为 Alpha，并在示意图中标为 API Preview，称它结合机密计算和严格、可验证的控制，目的是在模型处理提示词和回答时保护这些内容。Altman 还提到，零数据保留（ZDR）与 Private Safety Processing 搭配使用，可以在不让 OpenAI 人员看到原文的情况下做自动安全审查。The Next Web 报道称，该功能此前在 DevDay 上作为秋季预览展示过；负责人 Shekar 把这次测试称为第一步，并表示公司正在准备更多计算资源以便更大范围推广，但没有给出时间表。参与测试的客户名单、定价、支持的模型，以及何时全面开放，目前均未公布。

- OpenAI 官方产品页 Private Intelligence（页面将 Private Inference 标为 Alpha / API Preview）：https://openai.com/business/private-intelligence/
- The Next Web，2026-11-25 19:27（GMT）／2026-11-26 03:27（香港时间）：https://thenextweb.com/news/openai-private-inference-testing-customers

### 对你的工作意味着什么

金融机构最关心的一点，往往是「把敏感材料交给外部模型时，处理过程中会不会被看到」。这次测试说明，大厂正在把保护从「用完不存」推进到「算的时候也隔离」。但它还是小范围、早期试用，不是已经对所有企业开放的产品，更不能理解成已经过独立核验、连运营方也绝对看不见——官方写的是机密计算和可验证控制，具体用什么芯片、客户如何核验、覆盖哪些步骤，仍有未公开细节。这不是使用或采购建议。

### 白话

**机密计算 / confidential computing** = 把计算放在芯片里一块对外隔离的安全区里跑，目标是让机房运营方也较难直接读到处理中的数据。**零数据保留 / ZDR** = 处理完成后不留下提示词和回答。**Private Safety Processing** = 在尽量不让 OpenAI 人员看到原文的前提下，做滥用检查。**Alpha / API Preview** = 还在早期试用，功能和条款都可能再变。

## 2. OpenAI 确认：12 月起 Plus、Pro、Business 将把 ChatGPT 和 Codex 的用量额度合并

### 发生了什么

OpenAI 帮助中心已说明，从 12 月起，Plus、Pro 和 Business 方案会把 ChatGPT 和 Codex 的用量额度合并计算（按 token），作为把 Work 的智能体能力并入 ChatGPT 主界面的一部分。Instant 对话不占用这笔额度。官方写，预计多数用户不必比现在更频繁地等待额度重置；可在设置里的 Usage 查看合并后的剩余额度和重置时间；用完后可以等待重置、升级方案，或购买积分以继续使用符合条件的功能。一小部分用户会在 12 月前先看到变化，以便收集反馈。TechCrunch 今天引述 OpenAI 发言人说，多数用户预计不会更频繁碰到重置，但最重度使用的一小部分人可能会更早触顶；发言人还说，Chat 和 Work 将共用一个用量计，用尽后仍可继续使用 Instant。The Verge 同样报道了 12 月起合并额度一事。产品负责人 Tibo 曾在 11 月 25 日凌晨向一小部分 Pro 用户试点合并后的 Chat 与 Work 界面（该条原帖发布于 2026-11-25 01:46，香港时间，略早于本次统计起点，仅作背景）。

### 参考来源

- OpenAI 帮助中心《Understanding ChatGPT and Codex usage limits》，页面标注更新于 2026-11-25：https://help.openai.com/en/articles/20001625-understanding-chatgpt-and-codex-usage-limits
- TechCrunch，2026-11-25 12:03 PM PST／2026-11-26 04:03（香港时间）：https://techcrunch.com/2026/11/25/openai-says-heavy-chatgpt-users-may-hit-limits-sooner-as-it-merges-chat-and-work/
- The Verge，2026-11-25 16:39（UTC）／2026-11-26 00:39（香港时间）：https://www.theverge.com/ai-artificial-intelligence/1042187/openai-is-combining-chatgpt-and-codex-usage-limits

### 对你的工作意味着什么

如果你平时既用 ChatGPT 聊天，又用 Work 或 Codex 写材料、改代码，12 月起这两边可能要共用同一笔额度，重度使用时就要留意重置时间。Instant 仍可用，且不计入这笔额度。具体以你账户里的官方说明为准。这是产品用量规则的变化，不是买卖或套餐推荐。

### 白话

**token** = 模型处理和生成文字的计量单位，可以粗略理解成「这次用了多少字和推理」。**Instant** = 较快、不走高级推理额度的即时对话模式。**Work / Codex** = ChatGPT 里偏工作的智能体和编程工具。

## 3. Google DeepMind 为 Antigravity 推出 Mass Spec Skills：给模型接上质谱工具后，公开谱库测试中准确率约 97%

### 发生了什么

Google DeepMind 发表文章称，今天推出面向 Google Antigravity 的 Mass Spec Skills（质谱技能包）。这套技能把 Gemini 的化学推理，与现有的质谱分析工具、公共化学数据库查询串在一起：由 Antigravity 代为执行，再把证据整理出来给化学家复核。官方用 100 张已收入公开参考谱库的质谱图做测试（每种谱图尝试 3 次），比较了轻量模型 Gemini 3.8 Flash，以及两款旗舰模型 Gemini 4 Argon、Gemini 4 Carbon。官方称：不联网、不用技能时，三个模型的准确率都低于 4%；加上这套技能后，三个模型都在约 97% 的尝试中识别并核验了准确分子，轻量模型的准确率与旗舰模型相当。这些数字来自 DeepMind 自己的评测：测试谱图来自 MoNA 中的 Enamine REAL MS/MS 合集，且化合物结构也已收录在 PubChem；超时 1 小时记为失败，短暂的基础设施和配额错误被排除。官方同时写了限度：常规谱库检索平均只能注释约 5% 的实测谱图（人体样本约 10%）；镜像分子和部分相近同分异构体无法仅靠这类谱图区分；真正的全新分子不在任何现有数据库里，系统也不能自行确认结构，只能给出分子式、碎片归属等起点，供化学家继续解析。该技能包现已可在 Antigravity 中安装；企业用户可用 Google Cloud 账号登录。官方还称，将向 1 万名科学家提供 6 个月最高用量档的免费使用，滚动录取，并取决于资格、名额和筛选，申请现已开放。

### 参考来源

- Google DeepMind 官方博客，标注日期 2026-11-25：https://deepmind.google/blog/interpreting-mass-spectra-with-google-antigravity/

### 对你的工作意味着什么

这不是日常写文案或做海报能直接用上的功能，但它把一件事讲得很清楚：给通用模型配上可靠的专业工具和数据库，比让它自己对着原始数据「蒙」，结果差得很远。文中 97% 是在「谱图已经在公开库里」的测试集上得到的官方内部评测，不能理解成真实未知样本也能识别到这个水平。这也不是买卖或投资建议。

### 白话

**质谱 / mass spectrometry** = 把分子打碎，称各块碎片的「重量」，用来推测它是什么化合物。**质谱图 / mass spectrum** = 这次测量得到的碎片「指纹」。**Antigravity** = Google 的 AI 智能体工作平台，可以调用技能和工具替人完成多步任务。**同分异构体** = 原子组成一样、结构不同的分子，有时碎法几乎相同，单看谱图分不开。

## 4. Anthropic 公开 Messages API 从 Python 迁到 Rust 的过程：用生产流量对照验证，并由 Claude 智能体修复差异

### 发生了什么

Anthropic 发表工程文章，回顾把面向客户的核心接口 Messages API 从 Python 迁到 Rust。该接口是客户以及 Claude Code、Cowork 等自家应用调用 Claude 的主要入口。官方称，从 2024 年初到 2026 年秋季，接口流量大约增长了 1,800 倍；Claude 大约用一周写出了核心请求路径的第一个版本，但要证明新接口与线上旧版行为一致，比写代码更难——迁移期间 Python 版仍在改动，同一请求的模型回复本身也不完全确定，而且团队不能阅读客户请求。他们的办法是把仍在运行的生产接口本身当成「核对器」：用线上流量对照两边的差异，再自动派智能体去修复。官方称，最终上线的 Rust 接口每请求 CPU 用量约降低 70%，中位「首个 token 时间」约缩短 20%，全程没有停机，也没有冻结功能开发。公开流量在 2026 年 9 月切到 Rust，因此这是一篇对已完成迁移的复盘，不是今天才切换的公告。文中 70% 和 20% 都是 Anthropic 自己的统计。官方还写到，到 2026 年 5 月，Anthropic 合并的代码里已有超过 80% 由 Claude 编写；在审计从 Python 移植过去的测试时，他们发现了 100 多处被减弱的断言。

### 参考来源

- Anthropic 官方工程文章，标注日期 2026-11-25：https://www.anthropic.com/research/migrating-api-to-rust
- Anthropic 官方 X 帖，2026-11-25 16:26:59（UTC）／2026-11-26 00:26:59（香港时间）：https://x.com/AnthropicAI/status/2125627317263466739

### 对你的工作意味着什么

这不是新模型发布，但对日常用 Claude、Cursor 或其他编程智能体很有参考：模型已经能承担大量代码工作，真正难的是怎么核验「改完以后和原来完全一样」，尤其是不能直接查看原始材料的时候。更稳妥的用法是先把「怎样算做对」写清楚，而不是只让它拼命写。文中百分比来自官方自己的复盘，转述时不要说成已被第三方普遍复现。

### 白话

**Messages API** = 外部程序和 Claude 对话的主要接口。**Rust** = 一种更侧重性能和内存安全的编程语言，常被用来改写高流量服务。**首个 token 时间** = 从发出请求到模型开始吐出第一个字的等待时间。**断言** = 测试里用来规定「这里必须是这样」的检查条件，被减弱后，有问题的代码也可能被测成通过。

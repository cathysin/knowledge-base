## 每日 AI 情报｜2026-11-18（周三）

**今天最大的事：** 英伟达公布了黄仁勋离职后的首份季报：第三季度营收 1,158 亿美元，同比增长 103%，并对下一季度给出约 1,300 亿美元的展望。同一时段，OpenAI 发布了更适合做专业材料的新模型 GPT-6.2，还推出了面向销售团队的 ChatGPT 插件；微软则在 Ignite 大会上拿出自研模型和一套企业透明度倡议。

## 1. 英伟达发布黄仁勋离职后的首份季报

### 发生了什么

英伟达公布截至 2026 年 10 月 25 日的 2027 财年第三季度业绩。官方新闻稿：营收 1,158 亿美元，较上一季度增长 20%，较去年同期增长 103%；数据中心业务营收 1,076 亿美元，环比增 21%，同比增 110%。按美国通用会计准则（GAAP），摊薄每股收益 2.70 美元，净利润 653 亿美元；非 GAAP 摊薄每股收益 2.68 美元。毛利率方面，GAAP 为 74.8%，非 GAAP 为 74.9%。公司称新一代机柜系统 Vera Rubin NVL72 已开始出货，是公司历史上爬坡最快的产品，目前已在 CoreWeave、Google Cloud、Microsoft Azure、Oracle Cloud 和 Nebius 等合作方机房运行。

对下一季度（2027 财年第四季，该季多一周），公司预计营收 1,300 亿美元，上下浮动 3%，并写明：这一展望没有计入来自中国的数据中心计算业务收入。这是公司在前任 CEO 黄仁勋上周离职后发布的首份财报，由临时 CEO 兼首席财务官科莱特·克雷斯（Colette Kress）对外说明。CNBC 援引 LSEG 的分析师预期称，营收预期约 1,091 亿美元、调整后每股收益预期约 2.48 美元，公司公布的数字高于这一对照；盘后交易中股价一度上涨超过 3%。另据 CNBC 和路透社对电话会的报道：董事会主席表示，此次不回答有关黄仁勋辞职的问题，也没有让他复职的计划；克雷斯还将 2028 财年营收增速展望由约 70% 上调至约 75%。后两项是媒体对电话会的转述，不是新闻稿原文。

### 对你的工作意味着什么

客户或同事今天很可能会把「财报数字」「中国业务展望」和「管理层变动」三件事一起问。分开说就好：营收、数据中心和展望来自公司新闻稿；「高于华尔街预期」是媒体用分析师数字做的对照；复职安排是电话会上的表态，仍要等董事会后续说明。讲清事实和时间即可，不要对股价或买卖下判断。

### 白话

**GAAP / 非 GAAP** = 两套记账口径，前者按官方会计准则，后者会调整部分项目，看新闻时不要混用。**数据中心业务** = 卖给云厂商和大型机构、用来训练和运行 AI 的芯片与系统，是英伟达目前最大的收入来源。**产品爬坡** = 新产品从少量出货到规模供货的过程。

## 2. OpenAI 发布 GPT-6.2 Astra 和 Sol：更适合做专业文稿，API 更便宜

### 发生了什么

OpenAI 发布新一代模型 GPT-6.2 Astra 和 GPT-6.2 Sol。官方介绍：Astra 面向最难的专业项目，在幻灯片、表格和文档上更贴近你给的模板，也更符合法律、销售、金融和会计等行业的写法，少套话、少空泛结论；Sol 面向日常工作，官方称比上一代 GPT-6.1 Sol 更聪明、更省额度，不少 OpenAI 员工已把它当作默认模型。Astra 的 API 输入和输出价格比 GPT-6 Astra 低 20%，缓存输入再打六折，标准价为每百万 token：输入 8 美元、缓存输入 0.40 美元、输出 40 美元；Sol 的 API 价格与 GPT-6.1 Sol 相同（输入 2 美元、缓存输入 0.10 美元、输出 10 美元）。这些评测和「成本更低」的对比来自公司自己公布的基准，不是第三方复验。

即日起，ChatGPT Work 和 Codex 向 Plus、Pro、Enterprise 和 Edu 用户开放这两个模型；Pro 500 用户可用 Ultrafast（更快档），Pro 200 用户首次也能用 Ultrafast，但先从 Sol 开始。开发者可在 API 调用 `gpt-6.2-astra` 和 `gpt-6.2-sol`。

- OpenAI 官方博客，页面标注 2026-11-17：https://openai.com/index/introducing-gpt-6-2-astra-sol
- OpenAI 官方账号 @OpenAI，2026-11-17 17:54（UTC）／2026-11-18 01:54（香港时间）：https://x.com/OpenAI/status/2122750126297161811

### 对你的工作意味着什么

这是过去 24 小时里，最贴近你写材料、做表格和整理说明的一次模型更新。如果团队已经在用 ChatGPT 付费版，可以先用 Sol 处理日常草稿，把更重的投研备忘、路演页和表格交给 Astra 试试。不过涉及数字、客户信息和对外口径，仍要自己核对；官方跑分只能当参考。

### 白话

**Astra / Sol** = 同一代里的两个档次，前者偏难任务和高质量成品，后者偏日常、更省钱。**API** = 把模型接到自己系统或工具里用的接口，按 token 计费。**缓存输入** = 重复送进去的相同内容可以按更低价格计费。**Ultrafast** = 同一模型的更快响应档，不是另一个新模型。

## 3. OpenAI 推出 ChatGPT for Sales：把销售调研、准备和跟进接到同一个对话框

### 发生了什么

OpenAI 宣布推出 ChatGPT for Sales。核心是一个新的 Sales 插件，加上 30 多个新增或升级的合作方插件，可把 CRM、线索工具、会议记录和设计工具里的信息接到 ChatGPT 里，用来筛选客户、准备拜访材料、写跟进、整理下一步，以及查看哪些交易可能卡住。官方点名的对接包括 Salesforce、HubSpot、Apollo、Clay、Outreach、Salesloft、Gong，以及用 Canva、Gamma、Figma 或 ChatGPT Slides 做演示稿。管理员可在 ChatGPT Business / Enterprise 后台为团队启用；功能和插件是否可用，取决于套餐、地区和工作区设置。

### 参考来源

- OpenAI 官方博客，页面标注 2026-11-17：https://openai.com/index/introducing-chatgpt-for-sales

### 对你的工作意味着什么

这和金融营销的日常很近：找客户、准备说明、会后跟进、把要点写回客户记录，都可以先在一个对话框里起草。如果公司允许使用，值得先看能否接到现有的 CRM 或资料库；接入前先确认权限和客户信息不能外泄。它给的是草稿和提醒，不能代替你对客户和口径的判断。

### 白话

**插件（plugin）** = 让 ChatGPT 读取或写入外部工具的连接件，例如客户管理系统。**CRM** = 用来记录客户、商机和跟进进度的系统。**Sales 插件** = OpenAI 自己做的销售工作流入口，再配合各家合作方插件一起用。

## 4. 微软 Ignite：推出一批自研模型，并拉40多家机构做 AI 透明度倡议

### 发生了什么

在旧金山举行的 Ignite 2026 上，微软发布了一批自研 MAI 模型，重点强调「接近一线模型的表现、但价格更低」。官方举例：MAI Code 2 面向日常企业编程，公司称在四项常用编程基准的平均成绩上，达到 GPT-6.1 Sol 约 98% 的表现、价格约 40%，达到 Claude Opus 5.5 约 96% 的表现、价格约 5%；更轻量的 MAI Code 2 Flash 已进入 GitHub Copilot，并在 Microsoft Foundry 提供有限预览。微软同时宣布「AI 透明度倡议」，与包括埃森哲、Adobe、毕马威、Mastercard、沃尔沃汽车在内的 40 多家机构合作，希望建立可跨模型、可被独立核验的透明、安全和治理标准，并逐步做到微软自家的 AI、Foundry 和 Copilot 产品中。上述性能和价格对比均为微软自己公布的评测。

### 参考来源

- 微软 AI 官方博客《Seven new world class models…》，2026-11-17：https://microsoft.ai/news/microsoft-ignite-2026/
- 微软新闻稿（AI 透明度倡议），2026-11-17：https://news.microsoft.com/source/2026/11/17/microsoft-and-organizations-across-industries-launch-ai-transparency-initiative-to-strengthen-enterprise-trust-in-ai-models-and-agents/
- 微软官方账号 @Microsoft，2026-11-17 18:36（UTC）／2026-11-18 02:36（香港时间）：https://x.com/Microsoft/status/2122760748849914041

### 对你的工作意味着什么

两层含义。一是办公软件里的 AI 选项可能很快变多、也更便宜，尤其是已经在用 Microsoft 365 或 GitHub Copilot 的团队。二是企业对「智能体到底做了什么、能不能事后查清」会越来越认真。如果以后向客户介绍 AI 工具，除了好用，也要能说清权限、记录和人工确认怎么安排。微软的跑分同样只是自家数据。

### 白话

**MAI** = 微软自己训练的模型系列，不完全依赖外部模型供应商。**Foundry** = 微软给企业选用、部署和管控各类模型的平台。**透明度倡议** = 大家商量一套公开标准，让公司能看清、核验和限制 AI 的操作，而不是只听模型自己的说法。

## 5. 谷歌把 Gemini「任务」功能免费推向多个国家，可代打电话和办事

### 发生了什么

谷歌宣布，Gemini 应用里的「任务（Tasks）」功能即日起向美国、日本、韩国、加拿大、澳大利亚和印度的免费用户分批开放，底层模型是 Gemini 4 Hydrogen。官方演示包括：同时给附近商家打电话并代为等候、把预约写进日历；在获得授权后查看账单或完成购物；把购物清单发到 Instacart。谷歌称，付款走 Agent Payments Protocol（AP2），正在与 Mastercard、Visa 合作，American Express 为即将支持；用户可预设消费上限，系统在点击「购买」前会征求确认或预授权。高级功能先从美国开始。香港不在此次免费开通名单里。Gemini 4 Hydrogen 模型本身于 11 月 12 日发布，今天新的是这项代办功能对免费用户开放。

### 参考来源

- 谷歌官方博客，页面标注 2026-11-17：https://blog.google/innovation-and-ai/products/gemini-app/tasks-in-gemini-free-new-features/
- 谷歌官方账号 @Google，2026-11-17 17:16（UTC）／2026-11-18 01:16（香港时间）：https://x.com/Google/status/2122740719559278830

### 对你的工作意味着什么

这代表消费级助手正在从「回答问题」走向「代为办事」。对你本人，这次名单不含香港，先不必期待马上能用。对工作更有参考价值的是：以后如果团队让 AI 代发消息、代付款或代改日历，必须先设好授权范围和人工确认，尤其是涉及客户资料和资金的步骤。

### 白话

**任务（Tasks）** = 不是只给建议，而是让 Gemini 连续完成打电话、下单、改日程等多步操作。**AP2** = 一套给 AI 代为付款用的协议，用数字令牌处理支付，而不是把完整卡号交给模型。**Hydrogen** = 谷歌 Gemini 4 系列里更偏快、偏日常执行的一款模型。
